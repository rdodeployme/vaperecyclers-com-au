# vaperecyclers.com.au

Static site (GitHub Pages). Pages are generated from `_src/pages/*.html` by `python3 _src/build.py`.

- Forms post to FormSubmit; the destination inbox is the `FORM_INBOX` line at the top of `js/site.js`. The first submission sends a one-off activation email to that inbox — click it once.
- Colours and type: `css/site.css` (`:root` tokens).
